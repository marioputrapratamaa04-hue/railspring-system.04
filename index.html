Konektor Cloud Supabase — RailSpring

Sinkronisasi otomatis arsip Excel pengujian pegas & Set Sarana P24/P48 tanpa server 24/7

Bagaimana Konektor Ini Bekerja di Project Anda?

Setiap kali Anda mengunggah file Excel baru/lanjutan atau menyimpan Set Sarana, RailSpring otomatis menyimpan datanya ke Supabase Database & Storage. Agar semua pengunjung website GitHub Anda langsung terhubung tanpa perlu mengisi kunci manual, Anda juga bisa menempelkan URL & Anon Key langsung pada variabel DEFAULT_SUPABASE_URL dan DEFAULT_SUPABASE_ANON_KEY di baris awal <script> file HTML ini.

Langkah Wajib Sekali di Awal: Jalankan SQL Ini di Supabase

Buka dashboard Supabase Anda → menu SQL Editor → tempel perintah di bawah ini lalu klik Run untuk membuat tabel railspring_state dan bucket railspring-storage secara otomatis:

-- 1. Buat tabel penyimpanan arsip Excel & Set Sarana RailSpring
create table if not exists public.railspring_state (
  key text primary key,
  value jsonb not null,
  updated_at timestamptz default now()
);

alter table public.railspring_state enable row level security;

drop policy if exists "RailSpring Public Read" on public.railspring_state;
create policy "RailSpring Public Read" on public.railspring_state for select to anon using (true);

drop policy if exists "RailSpring Public Insert" on public.railspring_state;
create policy "RailSpring Public Insert" on public.railspring_state for insert to anon with check (true);

drop policy if exists "RailSpring Public Update" on public.railspring_state;
create policy "RailSpring Public Update" on public.railspring_state for update to anon using (true);

-- 2. Buat bucket Storage untuk menyimpan file .xlsx asli
insert into storage.buckets (id, name, public)
values ('railspring-storage', 'railspring-storage', true)
on conflict (id) do update set public = true;

drop policy if exists "RailSpring Storage Read" on storage.objects;
create policy "RailSpring Storage Read" on storage.objects for select to anon using (bucket_id = 'railspring-storage');

drop policy if exists "RailSpring Storage Upload" on storage.objects;
create policy "RailSpring Storage Upload" on storage.objects for insert to anon with check (bucket_id = 'railspring-storage');

drop policy if exists "RailSpring Storage Update" on storage.objects;
create policy "RailSpring Storage Update" on storage.objects for update to anon using (bucket_id = 'railspring-storage');
